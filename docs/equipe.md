## :material-source-branch: Como contribuímos

| Item | Convenção |
| :--- | :--- |
| **Repositório** | [github.com/felipegf1/docs-grupo3-tppe](https://github.com/felipegf1/docs-grupo3-tppe) |
| **Branch principal** | `main` — protegida, alterada apenas por *pull request* |
| **Branches de trabalho** | `branch-<nome>` para trabalho individual e `feat/<QRO-XX>` para itens do backlog |
| **Publicação** | Automática via GitHub Actions a cada push na `main` |
| **Rastreabilidade** | Todo *pull request* referencia o item do [backlog](backlog/index.md) que atende, no formato `QRO-XX` |

## :material-clipboard-text-clock-outline: Divisão do trabalho

O trabalho é organizado pelos épicos do [backlog do produto](backlog/index.md). Cada sprint fecha com a documentação afetada atualizada no mesmo *pull request* da entrega, conforme a *Definition of Done*.
